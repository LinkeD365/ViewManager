# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
**Report a vulnerability** feature on this repository to submit a private
vulnerability report. If that feature is unavailable, contact a repository
maintainer privately through GitHub. Include the affected version, steps to
reproduce, and any relevant impact details.

Reports will be reviewed by the repository maintainers. Please allow time for
assessment and a coordinated fix before publicly disclosing a vulnerability.
